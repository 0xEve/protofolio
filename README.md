# Abdelrhman Islam — Portfolio

Next.js + Tailwind CSS + Framer Motion.

## Run
npm install
npm run dev

## Edit content
All content lives in data/profile.js — name, projects, skills, certifications, stats.

## CV
Place your CV file at public/resume.pdf so the Download CV button works.

## Dark mode
Toggle button in the navbar. Preference is saved in localStorage.
